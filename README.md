# Atelier Diario · Lectura, Voz, Mente y Calma

Aplicación web progresiva (PWA) instalable en móvil y PC para el crecimiento diario sin ruido visual (con **Modo Día** y **Modo Noche**).

## Módulos
- **Biblioteca y Lector Online:** Wikisource (textos completos en español), Wikipedia y Open Library + diccionario al doble clic con Wikcionario.
- **Taller de Caligrafía:** lienzo de trazado con renglones guía e inclinación de 55°.
- **Ortografía, Vocabulario y Criterio:** retos de ortografía con reglas explicadas, reemplazo de muletillas, glosario personal y modelos mentales.
- **Estudio de Canto:** afinador vocal en vivo mediante micrófono + piano de referencia + escalas guiadas.
- **Centro de Calma (`SOS Calma`):** respiración guiada (`4-7-8`, `Caja 4-4-4-4`, `Suspiro fisiológico`), aterrizaje sensorial `5-4-3-2-1` y diario de reencuadre positivo.
- **Puente con UNUmbral y OMNI ARENA:** lectura automática de `UmbralDB` en el mismo origen de GitHub Pages (o importación de respaldo `.json`) para mostrar huecos libres y tareas críticas del día.
